# 珠宝黄金门店经营助手

当前优先实现 PC 工具站，定位为“珠宝黄金门店目标拆解 + 每日战报助手”。小程序目录先保留，后续需要移动端时再继续。

## 项目结构

```text
apps/
  web/           PC 工具站，静态 HTML/CSS/JS
  miniprogram/   微信小程序原生项目，暂缓
docs/            产品和数据设计文档
```

## PC MVP

- 设置月目标或周目标、周末倍率、节假日/活动日倍率
- 一键加载 2026 年法定节假日，并可继续追加门店自定义活动日
- 自动拆解每日目标
- 录入每日销售额、克重、件数、客单数
- 可选录入黄金、彩金/K金、钻石/镶嵌、其他品类明细，不填写也不影响基础战报
- 录入每日门店金价，并展示国际金价、国内基准、门店零售价的调价口径
- 日历展示每日目标、完成额、完成率
- 自动生成微信群战报文案
- 本地自动保存配置和录入数据

## 本地打开

直接用浏览器打开 `apps/web/index.html`。当前版本使用浏览器本地存储，不依赖后端。
